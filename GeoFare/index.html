A role-aware GIS fare computation and management system for commuters, habal-habal riders, and authorized transportation management personnel.
🌱 Why this was made

With the implementation of the new Habal-Habal Flexible Fare Matrix under Joint Resolution No.1 s. 2026, many passengers — especially the elderly and those unfamiliar with technology — are unaware of the official fares. This leads to confusion, and sometimes overcharging.

GeoFare was built to put the official fare matrix in everyone's pocket, with an easy map-based calculator so anyone can know exactly how much their ride should cost before they even mount the motorcycle.

GeoFare does not provide ride booking, payments, live tracking, or emergency dispatch.

⚙️ How it works

The map uses OpenStreetMap data. When you drop a pickup and drop-off pin, the app calculates the actual road distance between both points using OSRM (Open Source Routing Machine) — the same road network your habal-habal driver follows — and references the official fare table to compute your fare instantly.

When Supabase is configured, authenticated records are stored in the application database. Development mode uses an isolated local mock data provider. The Report feature generates a printable slip you can use when filing a complaint with the LGU or MFRTA.
